# Barath R — 3D Developer Portfolio

A cinematic, interactive 3D developer portfolio website built for **Barath R** (Aspiring Software Engineer & B.E. student in Artificial Intelligence & Data Science).

![Portfolio Preview](public/barath.jpg)

## 🚀 Tech Stack

- **Framework**: React 18 + Vite
- **3D Graphics & WebGL**: Three.js + React Three Fiber + Drei
- **Animations & Parallax**: GSAP (ScrollTrigger) + Framer Motion
- **Smooth Scroll**: Lenis
- **Styling**: Tailwind CSS (Glassmorphism & Custom Design Tokens)
- **Deployment Target**: Vercel / Netlify (Static Build)

## ✨ Features

- **Movie Studio Intro Loader**: Cinematic anamorphic lens flare sweep, telemetry status, and widescreen title reveal.
- **Interactive 3D Hero Scene**: Instanced particle field (200 points), wireframe distorted shapes, light beams, and 3D camera warp zoom-in entrance.
- **Global Sci-Fi 3D Background**: Dynamic 3D perspective grid floor that shifts tilt on scroll, 3D shape parallax, and starfield grid.
- **About Section**: Portrait photo with glassmorphism card frame, glowing cyan/purple borders, and interactive stat counters.
- **Skills Grid**: Interactive CSS 3D tilt cards with scroll-triggered proficiency progress bars and category filtering.
- **Projects Showcase**: Tilt-on-hover project cards with tech tags and direct GitHub / Live demo links.
- **Experience Timeline**: Vertical glassmorphism timeline for internships and work history.
- **Education & Certificates**: Status badges and grade highlights.
- **Interactive Contact**: Sci-Fi wireframe SVG globe and glass contact form.

## 🛠️ Local Setup & Running

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
